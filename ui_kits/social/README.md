# Social UI kit

Instagram templates at true export size, shown scaled.

| Template | Size | Use |
| --- | --- | --- |
| Pricing story | 1080×1920 | The salon's existing pricing story, rebuilt on the system — bone card on black, dotted leaders, script sign-off |
| Stylist highlight | 1080×1080 | Split portrait / name / specialties — the "highlights" pattern the owner asked to mirror |
| Mission post | 1080×1080 | Bone field, italic Bodoni mission statement, diamond ornament |
| Service card | 1080×1080 | Full-bleed photograph, scrim, service name and starting price |
| Feed grid | 3-up | How the work reads in the profile grid |

Type is scaled up proportionally at these sizes — the story headline runs 104px, body 30px. Do not use the website's 16px body on a 1080px canvas.
