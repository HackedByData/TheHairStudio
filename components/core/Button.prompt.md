The primary action: uppercase, tracked, square-cornered.

```jsx
<Button variant="primary" size="lg" icon="arrow-right">Book an appointment</Button>
<Button variant="secondary">View the menu</Button>
<Button variant="light" size="sm">Call the salon</Button>
```

`primary` is oxblood fill — one per view. `secondary` is a hairline outline. `light` is bone fill, for use on photography. `ghost` for tertiary. Press state is a 1px downward nudge, never a scale.
