The only icon source — a Lucide glyph at the house 1.5px stroke.

```jsx
<Icon name="scissors" size={18} />
<Icon name="map-pin" size={16} label="Location" />
```

24 glyphs are bundled (see `assets/icons/`). Never mix in a second icon set, never use emoji, and never draw a one-off SVG. Stroke weight is 1.5 everywhere; 1.2 only inside filled stars.
