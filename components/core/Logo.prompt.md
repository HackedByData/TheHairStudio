The wordmark, in three lockups.

```jsx
<Logo variant="type" size="sm" />
<Logo variant="stacked" size="lg" />
<Logo variant="mark" src="../../assets/logo-mark-white.png" />
```

`type` is a single tracked line — the default in headers. `stacked` mirrors the printed lockup. `mark` is the supplied raster, white on transparent: set `src` to the correct relative depth. Never recolour the mark, never place it on bone without inverting.
